Credentials

Each model points at one credential, and several models can share the same one. A static credential holds a literal API key; the OAuth kinds read (and refresh) their token from a CLI credential file on disk. An anthropic_oauth credential can instead hold a literal long-lived token in its secret field — the secret wins over the file.
