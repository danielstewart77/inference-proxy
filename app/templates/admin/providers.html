Providers

A provider is an upstream: a host, a credential, and one path per request shape it serves. Models attach to a provider and carry only their own name and pricing, so a locally-hosted model reachable at both /v1/messages and /v1/responses is offered to a Claude harness and a Codex harness from one row. Leave a path blank when the upstream does not speak that shape — Anthropic serves Messages only.
