Models

A deployment names a model and points at the provider hosting it; the provider supplies the host, the credential and one path per request shape, so a model reachable in more than one shape is offered to every harness that speaks one. Restrict a model to particular harnesses only to withhold it from one it would otherwise reach. A deployment with no provider falls back to its own full target URI and serves the single shape that path implies.
